# VELVET Studio Beauty

Site institucional e de alta conversão para o estúdio de beleza de luxo **VELVET Studio Beauty**.

## 💎 Identidade & Design System
- **Paleta de Cores:** Dark Glamour & Rose Gold (Obsidiana `#0F0A0E`, Berinjela `#1A1118`, Rose Gold `#E5B299` -> `#D48C70`, Berry `#9E3B63`).
- **Tipografia:** *Syne* (Headings fashionistas) e *DM Sans* (Corpo ultra nítido).
- **Componentes:**
  - Header Flutuante estilo Pílula Glassmorphism com navegação suave e drawer mobile.
  - Hero Tríptico Visual com 3 cards de closes em alta resolução.
  - Vitrine Visual com 6 categorias integradas ao montador interativo.
  - Combos Day Spa VIP destacados para aumento de ticket médio.
  - Comparador Interativo Antes & Depois (slider responsivo com 3 casos reais) + depoimentos em formato Direct.
  - Seção da Fundadora com storytelling assimétrico e badges de autoridade.
  - Montador Inteligente de Agendamento (Calculadora de Desejos) com montagem de mensagem dinâmica e disparo para WhatsApp.
  - Bastidores, Biossegurança hospitalar e Accordion FAQ.
  - Footer Boutique com rotas rápidas e botão flutuante.

## 🚀 Tecnologias
- HTML5 Semântico
- Tailwind CSS (via CDN)
- Lucide Icons
- JavaScript Moderno (Vanilla)
